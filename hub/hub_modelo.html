Hub de Automações

Escolha os indicadores e o período. O hub monta um pacote que baixa as planilhas no seu computador, sem precisar de terminal.

1

O que você quer baixar?

Embaixo de cada nome, o filtro que ele usa.
2

Qual período?

Os indicadores marcados não usam filtro de período. Siga para o passo 3.

Período (datas)

Em branco, cada sistema usa o período que já vem selecionado nele (em geral, o mês atual).

Ciclos (Venda Direta)

Para um ciclo só, preencha apenas o primeiro. Para vários (ex.: 7 a 13), preencha os dois. Em branco, usa o ciclo atual.

Escolher quais ERs baixar

A visão geral (GMS) sempre vem. Menos ERs deixa a execução mais rápida.

Campanhas (Ação de Fluxo)

Clique numa campanha para adicioná-la. Se uma campanha nova não estiver na lista, digite o nome.

3

Baixar o pacote

Ver a configuração que será enviada 

    

  


  

    
Depois de baixar

    
    
      
  1. Descompacte o zip (botão direito, Extrair tudo) numa pasta fixa, como Documentos.
    2. 
      
  2. Dê dois cliques em INICIAR.bat. Na primeira vez ele prepara o computador, o que leva alguns minutos. Não precisa abrir a pasta "programa".
    3. 
      
  3. Informe seu login da Extranet e do Medallia quando pedir. Fica salvo só neste computador.
    4. 
      
  4. O Chrome abre e baixa as planilhas sozinho. Não mexa nele. No fim, abre a pasta saida com as planilhas.
    5. 
    

    
Precisa de Windows e Google Chrome. Se algo der erro, envie o arquivo log.txt da subpasta mais recente de saida para quem mantém o hub.

  


  
Os arquivos baixados e o login ficam no seu computador. Nada é enviado para este hub. Versão __VERSAO__.
